# ATLAS Layout — DXF iPad prototype

Open `index.html` through the GitHub Pages HTTPS site in Safari. Do not open the HTML file from iPad Files/Quick Look.

Demo drawing loads automatically. DXF import currently supports ASCII LINE, LWPOLYLINE and POINT entities; this is a virtual station prototype, not a field-ready layout instrument.

## GitHub Pages
Repository Settings → Pages → Build and deployment: Deploy from a branch → main → /(root) → Save.

Test demo before importing large project drawings. Avoid uploading proprietary construction plans to a public repository; select DXF locally in Safari instead.
